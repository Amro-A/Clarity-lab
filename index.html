    Help and frequently asked questions

    How do I add a task?

    Type a short description in the New task field, then select Add task or press Enter. Try a specific action such as “Read chapter three” or “Submit the lab report.”

    How do I mark something complete?

    Select the checkbox next to a task. Completed tasks appear crossed out. Select the checkbox again if you need to reopen a task.

    What do the filters do?

    All shows your entire list. Active shows unfinished tasks. Completed shows tasks you have finished. Switching filters does not delete anything.

    How do I remove tasks?

    Select Delete beside a task to remove it immediately. Clear completed removes all finished tasks, including those hidden by the current filter. These actions cannot be undone.

    Will my tasks stay after I refresh?

    Tasks are saved in this browser when browser storage is available. They are not shared between browsers or devices. Clearing browser data removes saved tasks, and private browsing may discard them when the private session ends.

    Why was my input rejected?

    A task must contain at least one character other than a space. Empty entries display an error below the input field. Descriptions can contain up to 120 characters.

    Can I use this on my phone?

    Yes. The layout adjusts to smaller screens, and you can add, complete, filter, and delete tasks using touch controls. Your phone keeps its own separate task list.
